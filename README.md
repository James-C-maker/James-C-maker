# Hi, I'm James.

I'm a business operator and non-traditional software builder exploring how AI and open-source software can improve real-world work.

I believe software should be designed from the perspective of the people who actually use it — especially frontline workers.

Too much enterprise software turns management requirements into additional work for employees(like me, hh). I want to explore a different direction:

**Bottom-up software that removes unnecessary human work instead of creating more of it.**

## What I'm working on

### Worker Matters

An open-source initiative for building software from the perspective of frontline workers in labor-intensive industries.

> **Technology should adapt to people, not make people adapt to technology.**

We believe workers should benefit from software simply by doing their work.

Enterprise software often gives management better information by asking frontline employees to perform more data entry, reporting, confirmation, and repetitive administrative work.

We want to explore a different approach:

**Start with real work. Understand the worker. Remove unnecessary actions. Let useful data emerge naturally from the work itself.**

Our first open-source project will be **Sample Room OS**, built around real workflows in garment sample rooms.

## Principles

- Frontline workers are users, not data-entry endpoints.
- Human input should be the last resort.
- Software should remove work, not relocate it.
- Operational data should emerge naturally from real work whenever possible.
- Every action we require from a worker should justify its existence.

## Current focus

Building **Sample Room OS** as the first real-world implementation of these ideas.
